# STELVIO 

Stwórz kompletną, nowoczesną i profesjonalną stronę internetową dla trenera piłki nożnej specjalizującego się w treningu indywidualnym, treningu pozycyjnym, motoryce, diagnostyce sportowej i rozwoju młodych zawodników.

GŁÓWNA INSPIRACJA

Jako inspirację dla poziomu wykonania, układu i dynamiki strony wykorzystaj:

TopFit – Modern Fitness / Gym WordPress Theme: https://preview.themeforest.net/item/topfit-a-modern-fitness-gym-and-lifestyle-theme/full_screen_preview/19531675

Nie kopiuj projektu TopFit 1:1.

Nie kopiuj jego kodu, logo, tekstów, grafik ani charakterystycznych elementów brandingu.

Wykorzystaj natomiast podobne zasady projektowe:

duże sekcje zdjęciowe

mocny hero

duża typografia

dynamiczne kompozycje

sekcje full-width

profesjonalny sportowy charakter

mocne CTA

animacje podczas scrollowania

asymetryczne układy

połączenie fotografii z grafiką

premium editorial / sport performance aesthetic

Strona ma wyglądać jak profesjonalna marka trenera piłkarskiego i performance coacha, a nie jak zwykła strona wizytówkowa.

1. IDENTYFIKACJA WIZUALNA

Bazuj na dostarczonych przeze mnie grafikach.

Pierwsza grafika przedstawia obecny kierunek komunikacji marki.

Druga grafika przedstawia tło / atmosferę wizualną, którą należy rozwinąć w profesjonalny system graficzny.

Główne kolory:

DARK NAVY / GRANAT

bardzo ciemny granat

niemal czarny

kolor głównego tła

TURKUS / CYJAN

intensywny turkus

symbolizuje rozwój, technologię, analizę i energię

BURGUND / BORDO / GŁĘBOKA CZERWIEŃ

drugi mocny kolor akcentowy

związany ze sportem, intensywnością i rywalizacją

ZŁOTY / ŻÓŁTY

używany oszczędnie

do wyróżnienia ważnych informacji, numerów, linii i elementów premium

BIEL

główny kolor tekstu na ciemnym tle

Kolory powinny płynnie współistnieć.

Można stosować subtelne przejścia:

DARK NAVY → TURQUOISE

oraz

DARK NAVY → BURGUNDY / RED

Nie stosuj przesadnych gradientów.

Gradienty mają wyglądać jak profesjonalne światło / poświata, a nie jak kolorowy landing page AI.

2. MOTYW GRAFICZNY — NETWORK / CONNECTION

Bardzo ważnym elementem identyfikacji ma być motyw widoczny na dostarczonych grafikach:

połączenia punktów / network / nodes / linie / sieć.

Wykorzystuj go jako subtelny element tła.

Motyw może symbolizować:

połączenie zawodnika z trenerem

analizę

rozwój

zależności motoryczne

podejmowanie decyzji

inteligencję boiskową

analizę danych

rozwój potencjału

Elementy network powinny być subtelne.

Nie mogą przeszkadzać w czytaniu tekstu.

Można zastosować:

cienkie linie

punkty

geometryczne połączenia

delikatnie świecące nodes

fragmenty sieci wychodzące poza sekcję

animowane pojedyncze punkty

delikatne particle effects

Animacja powinna być bardzo subtelna.

26. NAJWAŻNIEJSZA ZASADA

Najpierw profesjonalny design, potem tekst.

Nie próbuj zmieścić wszystkich informacji w hero.

Użytkownik ma przechodzić przez stronę w logicznej kolejności:

ZOBACZ → ZAINTERESUJ SIĘ → POZNAJ METODĘ → ZOBACZ KOMPETENCJE → POZNAJ PROGRAMY → ZOBACZ PROCES → SKONTAKTUJ SIĘ

Strona ma prowadzić użytkownika do kontaktu, ale bez agresywnego marketingu.

Dodatkowo dla Lovable

Użyj dostarczonych przeze mnie grafik jako visual reference / brand reference. Nie traktuj ich jako finalnych elementów strony. Odtwórz ich kolorystykę, atmosferę, motywy i hierarchię informacji w profesjonalnym, responsywnym interfejsie.

Nie umieszczaj znaku „Made with AI” widocznego na jednej z grafik.

Nie umieszczaj tekstu jako części obrazu. Wszystkie teksty mają być prawdziwym HTML-em, aby można było je edytować, indeksować przez Google i poprawnie skalować na urządzeniach mobilnych.

Wszystkie dane, których nie podano, oznacz jako łatwe do późniejszej edycji placeholdery zamiast wymyślać fakty.
